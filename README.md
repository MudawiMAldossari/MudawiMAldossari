## Featured project

### [Saudi Public Finance Dashboard](https://github.com/MudawiMAldossari/saudi-public-finance-dashboard)

A six-page Power BI dashboard of Saudi government revenue, expenditure, fiscal balance and public debt, FY2017 to FY2025, built from eight Ministry of Finance reports. The data is validated in Python with 53 consistency checks.
